# Metadata stream

Metadata files are the machine-readable ledger for the numbered scientific stages. Read them alongside the matching report:

| Stage | Metadata role |
|---|---|
| `01` | Target features, structure manifest, numbering and canonical mappings |
| `02` | Candidate regions, binder epitope evidence, residue ledger, pair geometry |
| `03` | Arm A/Arm B design anchor sets |

Do not interpret a metadata table without its numbered report, because computational anchors, experimental contacts, and canonical residue mappings have different evidence status.
