# Working-stage stream

`work/` contains intermediate analysis areas. Numbered directories follow the same workflow order as `reports/` and `results/`. Durable conclusions must be copied into the matching report and result directory before a milestone is complete.

- `01_target_preparation/`
- `02_epitope_selection/`

Additional working directories should use `NN_description/` naming and must be recorded in `reports/00_06_status.md`.
