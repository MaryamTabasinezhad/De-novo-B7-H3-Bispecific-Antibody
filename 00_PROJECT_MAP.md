# B7-H3 project map

Open the numbered streams in this order:

1. `reports/00_*.md` — scope, decisions, and live status.
2. `data/` and `metadata/` — target inputs and machine-readable ledgers.
3. `reports/01_*` and `work/01_*` — target preparation.
4. `reports/02_*` and `work/02_*` — epitope evidence and pair geometry.
5. `reports/03_*` — design anchors.
6. `reports/04_*`, `tools/04_*`, and matching results — RFantibody and ProteinMPNN design/QC.
7. `reports/05_*`, `tools/05_*`, and `results/05_*` — RF2 validation and shortlist.
8. `reports/06_*`, `tools/06_*`, and `results/06_*` — independent AF3/RF3 validation.
9. `reports/07_*` — candidate accounting and advancement decision.

`README.md` provides project context. `reports/README.md`, `results/README.md`, `tools/README.md`, `data/README.md`, and `metadata/README.md` provide stream-specific indexes. `00_06_status.md` is the current state record.
