# AlphaFold 3 full RF2-shortlist validation outputs

This directory is reserved for derived summaries and reviewable outputs from
report `reports/06_02_alphafold3_shortlist_campaign.md`. The campaign covers
40 Arm A and 29 Arm B RF2 task-deduplicated inputs, with two seeds and two
samples per input (up to 276 predicted complexes). Large AF3 model files remain
in documented scratch storage; only inspected, derived artifacts are copied
here after the Slurm run.
