# Dual-Fab AF3 completed-structure archive

This archive contains the completed dual-Fab AlphaFold3 predictions currently available from the three-category campaign. It includes each available predicted complex in mmCIF format (`*_model.cif`) together with its ranking scores and summary-confidence JSON files.

- Source scratch directory: `/scratch/ghaedi/mab/fab_category_outputs/fab_AB_pairs/`
- Campaign: Arm A + Arm B dual-Fab on one shared human 4Ig B7-H3 target
- Structure format: mmCIF, generated by AlphaFold3
- Archive contents: see `file_manifest.txt` inside the archive
- These are computational structural predictions; they are not experimentally confirmed binders.

The full AF3 raw output tree remains in scratch because it includes large intermediate files. The archive is the durable Git-tracked copy of completed structures and key metadata.
